## Why it matters

Everything in this site assumes Git is installed and runs from your terminal. It's a small, fast install with no dependencies to worry about.

## macOS

The quickest route is Apple's Command Line Tools, which bundle Git:

```bash
xcode-select --install
```

If you use [Homebrew](https://brew.sh), you can install the latest version directly instead:

```bash
brew install git
```

## Windows

Install via `winget`, Windows' built-in package manager:

```powershell
winget install --id Git.Git -e --source winget
```

This installs **Git for Windows**, which includes Git Bash — a Unix-style terminal that makes the rest of this site's commands work exactly as written. If you'd rather use an installer, download one from [git-scm.com/downloads/win](https://git-scm.com/downloads/win) and keep the default options.

## Linux

Use your distribution's package manager:

```bash
# Debian / Ubuntu
sudo apt update && sudo apt install git

# Fedora / RHEL
sudo dnf install git

# Arch
sudo pacman -S git
```

## Confirm it worked

Open a fresh terminal window and check the version:

```bash
git --version
```

You should see something like `git version 2.45.0`. Any reasonably recent version (2.30+) is fine for everything covered on this site — a few advanced commands mention the version they were introduced in.

<Callout type="warning">
If the command isn't found on Windows, make sure you opened a **new** terminal window after installing — PATH changes don't apply to windows that were already open.
</Callout>

## Try it yourself

Run `git --version` right now. If you see a version number, you're ready for [First-Time Setup](/git/fundamentals/first-time-setup), where you'll tell Git who you are.
