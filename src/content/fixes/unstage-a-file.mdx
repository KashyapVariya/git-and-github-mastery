## Diagnosis

The file's *content* is fine — you just don't want it included in the next commit yet. This only affects the staging area, not your actual edits.

## Fix

```bash
git restore --staged path/to/file.js
```

The file moves back to "modified, not staged" — your edits are untouched, `git status` just stops listing it under "Changes to be committed."

**Using an older Git version without `restore`?** The equivalent is:

```bash
git reset HEAD path/to/file.js
```

<Callout type="tip">
Want to unstage *everything* at once? Run `git restore --staged .` — it clears the whole staging area in one go.
</Callout>
