## Diagnosis

You have not pushed yet, and the last commit on your branch is the one you want gone. As long as you haven't pushed, this is completely safe to undo.

## Fix

**If you just want to edit the last commit** (add a forgotten file, fix the message), amend it instead of resetting:

```bash
git add forgotten-file.js
git commit --amend
```

**If you want to undo the commit but keep the changes, staged and ready to recommit:**

```bash
git reset --soft HEAD~1
```

**If you want to undo the commit and unstage the changes**, so they sit as normal edits in your working directory:

```bash
git reset --mixed HEAD~1
```

**If you want to throw the commit and its changes away entirely:**

```bash
git reset --hard HEAD~1
```

<Callout type="warning">
`--hard` deletes the changes from your working directory too. Only use it if you're certain you don't want that work — or run `git reflog` afterward if you change your mind; the commit is usually still recoverable for a while.
</Callout>

<Callout type="golden">
Already pushed this commit? Don't reset — use `git revert HEAD` instead. Rewriting pushed history breaks things for anyone who already pulled it.
</Callout>
